# Dukenim — рабочая спецификация

Проект реализуется целиком по исходному мастер-ТЗ. Ограничение «только один шаг за запуск» снято владельцем проекта 3 августа 2026 года. Разрешено последовательно реализовывать и проверять все шаги 1–13 без ожидания ручного подтверждения между шагами.

Обязательные принципы сохраняются: Next.js 15, strict TypeScript, Supabase, RLS-мультитенантность, целочисленные цены в тенге, остатки только через `stock_movements`, серверная проверка ролей, изолированный платёжный модуль и отсутствие секретов на клиенте.
