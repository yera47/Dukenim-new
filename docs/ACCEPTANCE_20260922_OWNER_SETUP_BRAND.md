Проверить обновлённые шапки в production. Повествовательное слово «Dukenim» в обычных текстах оставлено текстом. |
| Новое создание магазина от первого шага до сохранения на телефоне | in progress | Сборка, TypeScript и схема проходят, но авторизованный браузерный путь после этого релиза ещё не завершён. Существующие магазины и данные не сбрасывались. |

Доставка Яндекса выполняется самим владельцем после заказа; прямой API Яндекса не подключён и цена для покупателя появляется только после согласования. Kaspi Pay выставляется и сверяется владельцем вручную; автоматический платёжный webhook не входит в эту функцию. SMS отложен по прежнему решению владельца.
