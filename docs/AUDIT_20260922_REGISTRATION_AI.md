Аудит базы Supabase: security advisor сообщил 8 закрытых RLS-таблиц без пользовательских политик (они обслуживаются сервером), 1 анонимно вызываемую `SECURITY DEFINER`-функцию и 22 функции для авторизованных. Анонимная `is_storefront_public(uuid)` по прочитанному определению возвращает только булево состояние публикации; менять её разрешения без проверки всех RLS-зависимостей нельзя. 22 функции содержат проверку `auth.uid()` или роли, но это **не** заменяет пооперационную проверку аргументов и tenant isolation. Advisor также сообщил, что защита от утёкших паролей выключена. [Справка по предупреждениям безопасности](https://supabase.com/docs/guides/database/database-linter?lint=0028_anon_security_definer_function_executable).

Performance advisor сообщил 7 внешних ключей без покрывающего индекса, 1 RLS policy с повторной оценкой auth-функции, 20 совпадающих permissive policy и 32 пока не использованных индекса. Это задачи для проверки планов запросов и нагрузки; удалять индексы только по счётчику нельзя. [Справка по индексам FK](https://supabase.com/docs/guides/database/database-linter?lint=0001_unindexed_foreign_keys), [по RLS initplan](https://supabase.com/docs/guides/database/database-linter?lint=0003_auth_rls_initplan).
