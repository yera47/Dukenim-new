# Dukenim: готовность к продажам — 2026-09-22

Статусы: `not started`, `in progress`, `verified`, `externally blocked`. Проверка кода и SQL не равна проверке оплаты покупателем, входа на другом устройстве или возврата реальных денег.

| Требование владельца | Статус | Доказательство и граница |
| --- | --- | --- |
| Ручная удалённая оплата Kaspi Pay | in progress | Настройка магазином, точная сумма заказа, ссылка или счёт на телефон, двойной шаг покупателя, сверка чека продавцом и защита неоплаченной выдачи реализованы. Production rollback проверил `pending → invoice_sent → paid → refunded` и запрет выдачи неоплаченного заказа. Браузерный заказ на опубликованной версии и платёж реальными деньгами ещё не проверены. |
| Автоматическая оплата картой и финансовые возвраты | externally blocked | Нет подключённого эквайера, merchant-аккаунта и разрешённого API для списаний/возвратов. Ручной статус Kaspi не означает автоматическую проверку денег. |
| Возврат оплаченного наличными заказа | in progress | Root RPC требует роли, номера заказа, точной суммы, реквизита и причины. Production rollback проверил успешный возврат, запрет обычному владельцу и отсутствие оставшихся тестовых записей. Сам перевод денег выполняется вне Dukenim. |
| Переписка с каждым владельцем | in progress | В обращениях добавлены Realtime-подписка, метки отправлено/прочитано и готовые ответы суперадминистратора. Production rollback проверил раздельные права на отметку прочтения. Браузерный тест двух одновременно открытых аккаунтов ещё нужен. |
| Суперадмин: новый экран и точные показатели | in progress | Главный экран переписан, добавлены ссылки на восемь разделов, магазин и общий чат. Сумма продаж считает только заказы с `payment_status=paid`, с явной границей последних 500 заказов. Остальные root-разделы не перестроены полностью. |
| Праздничное оформление через AI | in progress | В AI Studio добавлены календарь фиксированных дат, предложение за семь дней, собственное событие и создание черновика дизайна/кампании существующим AI-потоком. Автоматической публикации и изменения всех текстов магазина нет. |
| Тёмно-синий акцент и логотип | in progress | Обновлены общие кнопки, навигация и главный root-экран; знак D остаётся чёрным, синий только порог и точка. Все экраны ещё не получили визуальную ручную проверку. |
| Отзыв всех сессий пользователя | not started | Supabase JWT остаётся действительным до истечения даже после отзыва refresh-сессий. Нужна проверка `session_id` для чувствительных действий и покрытие RLS; кнопка без этой защиты не добавлена. |
| Восстановление из резервной копии | externally blocked | Нужен доступ к резервным копиям Supabase и отдельная тестовая среда для восстановления. CSV аудита не является резервной копией. Production-восстановление без проверенного snapshot не выполнялось. |
| Реальные CRM-подключения | externally blocked | Для каждой CRM требуется разрешённый аккаунт и проверенный обмен конкретного клиента. Существующие заявки и подготовленные пилоты не равны работающей интеграции. |
| Измерения на физических телефонах | externally blocked | Доступен браузерный мобильный viewport; физический телефон и воспроизводимые полевые измерения в этой сессии отсутствуют. |
| Удаление старых аккаунтов, магазинов и цифр | in progress | В production найдены 23 аккаунта, 20 магазинов и 5 заказов, из которых 4 оплачены. Массовая очистка ожидает точной границы от владельца; реальные финансовые записи не удалялись. |
| SMS | externally blocked | Владелец явно отложил подключение; доставка не включалась и не выдаётся за работающую. |

Azure: конфигурация, квоты и расходы не менялись. SQL-проверки выполнялись с откатом; реальных магазинов и заказов они не изменили.
