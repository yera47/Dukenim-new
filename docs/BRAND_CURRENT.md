# Dukenim — текущие правила логотипа

Решение владельца уточнено 2026-09-23. Геометрия берётся только из исходного знака брендбука; цветовая правка затрагивает порог и точку.

- Сохранить существующую геометрию официального знака D, включая нижнюю ступеньку.
- Знак и слово: тёмные на светлом фоне, белые на тёмном.
- Только плоский порог непосредственно внутри дверного проёма и точка после `dukenim`: голубые `#6FB9E8`. Боковые скосы и остальное основание буквы D остаются цветом основной формы.
- Шрифт сайта — Manrope; пропорции и расположение логотипа не менять.
- Нельзя заменять знак обычной текстовой буквой D, перерисовывать его силуэт или менять пропорции.

## Статус переноса

Общий веб-компонент использует экспорт исходного официального PNG с сохранённой альфой и геометрией. Тёмный и инверсный варианты меняют только цвет основной формы; порог остаётся голубым.

Старые PDF `output/pdf/Dukenim_Brandbook_2026.pdf` и `dukenim-brandbook.pdf` остаются историческими по цвету. Текущие web/mobile assets сохраняют их точную геометрию, но применяют новый голубой порог. Встроенные логотипы в старых видео отдельно не пересобирались.
