# Dukenim

Production-ready MVP мультитенантной SaaS-платформы для запуска интернет-магазинов: публичная витрина, корзина и оформление заказа, кабинет владельца, тарифы и superadmin-панель.

## Что реализовано

- Мультитенантная архитектура и изоляция данных через Supabase RLS.
- Регистрация, вход и серверная проверка ролей `owner`, `staff`, `superadmin`.
- Витрина `/s/[slug]`, каталог, корзина, checkout и PWA-манифест магазина.
- Кабинет владельца: товары, остатки, заказы, клиенты, аналитика, обращения и настройки.
- Тарифы Basic / Standard / Pro и серверные ограничения возможностей.
- Superadmin: магазины, выручка, статусы, тарифы, обращения и создание владельцев.
- Атомарные SQL-функции для заказов, остатков, офлайн-продаж и подписок.
- Подготовка к Vercel, Supabase и домену `dukenim.kz`.

## Локальный запуск

```bash
npm install
copy .env.example .env.local
npm run dev
```

Заполните `.env.local` реальными ключами Supabase. Адрес локального сайта: `http://localhost:3000`.

## Демо-данные

После выполнения `supabase/seed.sql`:

- витрина: `/s/demo-shop`;
- владелец: `owner@dukenim.kz` / `DukenimOwner123!`;
- superadmin: `root@dukenim.kz` / `DukenimRoot123!`.

Перед публичным запуском обязательно смените оба демо-пароля.

Полная инструкция публикации: [DEPLOYMENT.md](./DEPLOYMENT.md).

> Онлайн-оплата сейчас использует безопасный mock-адаптер. Для настоящего приёма денег нужно заменить реализацию `processPayment()` в `src/lib/payment.ts` после получения официальных merchant-реквизитов платёжного провайдера.
